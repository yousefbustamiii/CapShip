## What is CapShip?

CapShip is a complete foundation for building iOS and Android applications with Capacitor. Instead of rebuilding authentication, backend, database, and native configuration for every new project, CapShip ships with all of it working, ready for you to customize and build upon.

Both the CLI and the server are **fully open source** (MIT). You own everything you build on top of them.

## Quick start

```bash
npx capship free        # Free starter tier — open source core
npx capship pro         # Full CapShip Pro — enter your license key when prompted
```
