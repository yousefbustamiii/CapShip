## What is CapShip?

CapShip is a complete foundation for building iOS and Android applications with Capacitor. Instead of rebuilding authentication, backend, database, and native configuration for every new project, CapShip ships with all of it working — so your time goes into the features that make your app different.

Both the CLI and the server are open source (MIT). You own everything you build on top of them.

## Quick start

```bash
npx capship free        # Free starter tier
npx capship pro         # Full CapShip Pro — requires a license key
```
